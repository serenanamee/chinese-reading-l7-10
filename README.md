# 中文閱讀教室 🀄

華語閱讀練習小工具，分兩個程度層：讀一篇短文，自動列出重點生字（附例句），
基礎層另外附文法重點與看圖說故事。

## 使用

用瀏覽器直接打開 `index.html` 即可，不需要安裝、不需要 build。

## 內容

### 基礎層（4 篇，對應《當代中文課程》第一冊第 7-10 課，約 CEFR A2）

原創短文（不是課本原文），主題對應第 7-10 課：
- 第7課．早上九點去KTV — 邀約、約時間
- 第8課．坐火車去臺南 — 交通、比較句「比」
- 第9課．放假去哪裡玩？ — 假期計畫、「打算」
- 第10課．臺灣的水果很好吃 — 味道形容詞、「又...又...」

每篇除了生字重點以外，還有：
- 「看圖說故事」：一張原創 SVG 插畫（純幾何圖形手繪，無版權疑慮），搭配 3 題引導問題（中英對照），讓學生看圖口說練習，不用寫整篇
- 「文法重點」：該篇對應的一個文法句型，附句型公式、中英文說明與例句

### 文化探索層（13 篇，約 CEFR A2+／B1-，銜接第二冊程度）

原創敘述短文（不是任何來源的原文），格式參考 [chinese-chat-grid](https://serenanamee.github.io/chinese-chat-grid/)：
純短文＋生字重點，不含文法卡片與看圖說故事。主題是文化差異與生活習慣觀察，共 6 類：
打招呼與稱呼、送禮與拜訪、吃飯禮儀、時間觀念、節日與慶祝、生活習慣小觀察。

### 共用功能

- 每篇課文上方即時顯示帶聲調拼音，可一鍵隱藏／顯示（練習不看拼音自己讀）
- 拼音以「詞」為單位連在一起顯示（例如「捷運站」的拼音連在一起，不是「捷／運／站」分開三段），符合漢語拼音正詞法的慣例；已知詞來自每篇課文的生字表，加上 `pinyin.js` 內建的常見代名詞／時間詞／招呼語清單，沒登記過的詞會安全地逐字顯示（不會拼錯，只是不會連在一起）
- 「生字重點」：從該篇課文原文挑出的生字，附中英文解釋與 2 句另外新寫的例句
- 字級切換（小／中／大），方便投影或不同閱讀需求
- 字級與拼音顯示偏好會存在瀏覽器 localStorage（換裝置不會同步）
- 手機版自動改為單欄版面

## 結構

- `index.html` / `style.css` / `app.js` — 網頁本體與互動邏輯
- `articles.js` — 課文資料（課文本身、生字、文法重點、看圖說故事引導問題，皆有穩定 id）
- `illustrations.js` — 看圖說故事的原創 SVG 插畫（以 articles.js 的 id 對應）
- `prefs-store.js` — 字級與拼音顯示偏好儲存層（封裝 localStorage 存取）
- `pinyin.js` — 拼音轉換 helper（封裝 pinyin-pro，含多音字人工校正、XSS 安全的 ruby HTML 產生）
- `vendor/pinyin-pro.min.js` — 拼音套件（已下載至本機，鎖定版本，見 `vendor/VENDOR.md`）
- `test/logic.test.js` — 純 Node 邏輯測試（拼音轉換、課文資料完整性、偏好儲存），執行：`node test/logic.test.js`

## 拼音套件

使用 [pinyin-pro](https://pinyin-pro.cn)（MIT 授權），詳見 `vendor/VENDOR.md`。
