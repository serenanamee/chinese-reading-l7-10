# 初級中文閱讀教室 🀄

對應《當代中文課程》第一冊第 7-10 課程度（約 CEFR A2）的華語閱讀練習小工具：
讀一篇短文，自動列出重點生字（附例句）與這篇對應的文法重點。

## 使用

用瀏覽器直接打開 `index.html` 即可，不需要安裝、不需要 build。

## 內容

- 4 篇原創短文（不是課本原文），主題對應第 7-10 課：
  - 第7課．早上九點去KTV — 邀約、約時間
  - 第8課．坐火車去臺南 — 交通、比較句「比」
  - 第9課．放假去哪裡玩？ — 假期計畫、「打算」
  - 第10課．臺灣的水果很好吃 — 味道形容詞、「又...又...」
- 每篇課文上方即時顯示帶聲調拼音，可一鍵隱藏／顯示（練習不看拼音自己讀）
- 「生字重點」：從該篇課文原文挑出的生字，附中英文解釋與 2 句另外新寫的例句
- 「文法重點」：該篇對應的一個文法句型，附句型公式、中英文說明與例句
- 字級切換（小／中／大），方便投影或不同閱讀需求
- 字級與拼音顯示偏好會存在瀏覽器 localStorage（換裝置不會同步）
- 手機版自動改為單欄版面

## 結構

- `index.html` / `style.css` / `app.js` — 網頁本體與互動邏輯
- `articles.js` — 課文資料（課文本身、生字、文法重點，皆有穩定 id）
- `prefs-store.js` — 字級與拼音顯示偏好儲存層（封裝 localStorage 存取）
- `pinyin.js` — 拼音轉換 helper（封裝 pinyin-pro，含多音字人工校正、XSS 安全的 ruby HTML 產生）
- `vendor/pinyin-pro.min.js` — 拼音套件（已下載至本機，鎖定版本，見 `vendor/VENDOR.md`）
- `test/logic.test.js` — 純 Node 邏輯測試（拼音轉換、課文資料完整性、偏好儲存），執行：`node test/logic.test.js`

## 拼音套件

使用 [pinyin-pro](https://pinyin-pro.cn)（MIT 授權），詳見 `vendor/VENDOR.md`。
